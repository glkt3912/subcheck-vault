# SubCheck 仕様駆動開発 Vault

## 📝 概要

SubCheck（サブチェック）プロジェクトの仕様書管理用Obsidian Vaultです。
仕様駆動開発（Specification-Driven Development）のアプローチで開発を進めます。

## 🗂️ フォルダ構成

### specs/

- プロジェクトの全仕様書をMarkdown形式で管理
- 要件定義、画面設計、API設計など

### dev-logs/

- 日々の開発進捗
- 技術的な調査結果
- 問題解決のログ

### design/

- UI/UXデザイン
- ワイヤーフレーム
- 画像・アイコン素材

### releases/

- バージョン管理
- 機能追加・修正履歴
- ユーザー向けアナウンス

## 🔄 ワークフロー

1. **Specify**: 仕様書の作成・更新
2. **Plan**: 開発計画の策定
3. **Tasks**: タスクの分解と管理
4. **Implement**: コードの実装と検証

## 🛠️ 使用ツール

- **Obsidian**: 仕様書管理
- **Spec Kit**: 仕様駆動開発支援
- **Claude Code**: AI支援開発
- **Git**: バージョン管理と自動同期
